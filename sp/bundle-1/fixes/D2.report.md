## Design choices worth review
- **N1:** the voice-on list is per turn (`voiceOnsAfterDispatch`), filtered at the close (`v <= closedAt`): a voice-on after the close never counts. For a lazy `reopenIfStale` close, `closedAt` = the moment the turn became stale (`max(dispatch, lastFinal, effectiveStop) + continuationMs`), not the call time. G6 covers it.
- Machine-wide `lastVoiceOnAt` from the spec was replaced by this per-turn list (equivalent for tick closes, correct for lazy closes where later voice-ons would otherwise hide earlier ones).
- `reopenIfStale` runs before the absorb check (G6 needs `lastClosed` from it).
- Spec's `onsetBeforeCloseMs` log field replaced by `onsetAgeMs` (final arrival minus onset): the machine does not return `closedAt`.
