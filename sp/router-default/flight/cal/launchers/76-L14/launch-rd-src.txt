## Source text of launch-rd.cmd and launch-rd-dry.cmd (router-default spec section 10 and 10.1, plan Task 18; flight-eq's launch-eq-src.txt re-pointed).
## Read by gen-launchers-rd.mjs only. A line starting with two hash signs is a note for the reader and is dropped. A line of the form
## "=== name ===" starts a section. Macros {{LABEL}} {{RUNLABEL}} {{LOG}} {{ERR}} {{NODE}} {{PROOFS1}} {{PROOFS2}} {{PASSES}} {{COMMIT}} {{T}} {{DEADLINE}} {{CTX}} {{EXTRA}}
## are expanded by the generator; nothing else is. The result is ASCII with CRLF line ends and is read back byte by byte by the generator itself.
## launch-rd.cmd = head-flight + common + guard-flight + tail-flight. launch-rd-dry.cmd = head-dry + common + guard-dry + tail-dry.
## The two guard sections differ by the --require-precheck argument of the real launcher and by the dry one logging the guard exit 10 (only g4-clock failed) without writing the error log.
## Style rule that cost a flight once: no parentheses, ampersand, pipe, caret or percent sign inside any echo of an if-block, and no rem line holds one either.
## %~dp0 is the folder of the launcher itself: the helpers sit beside it, the run happens with the working directory MAIN.

=== head-flight ===
@echo off
rem Flight rd, task Natively-flight-rd: the router-default hour, NATIVELY_LIVE_ROUTER=1 on the live40 roster on MAIN at the registered HEAD, flight label {{RUNLABEL}}.
rem Registration PREREGISTER-router-default.md. ONE change under test: the Live router and the arbiter. Everything else is the shipped default: the verbal hedge is ON because its variable is cleared, no model or thinking override, Deepgram plus the Live ear, the focused Flash arms OFF by NATIVELY_FLIGHT_FOCUSED=off, the earlier-question block OFF because its variable is cleared.
rem Generated by gen-launchers-rd.mjs from launch-rd-src.txt. Never edit this file by hand and never with sed: change the source text and re-run the generator, which reads the bytes back.
rem NATIVELY_FLIGHT_COMMIT, NATIVELY_RD_T, I60_PROBE_DEADLINE_MIN and NATIVELY_ROUTER_CONTEXT_SHA12 below hold PLACEHOLDERS until the controller arms the launcher: node gen-launchers-rd.mjs with --commit, --t, --deadline-min and --ctx-sha12. The commit here and T are checked by the guard, the context sha by the guard against RESULT-smoke.md.
rem Knowledge mode ON is a persisted setting, not an environment variable: guard-rd.mjs reads it from the settings file.
rem Error log: natively-rd-launcher-error.log in the TEMP folder must not exist at arming. Launcher log: interview60.runs, flight-rd.launcher.log, in MAIN.
rem Exit codes: 9 wrong folder, 8 audio missing, 7 roster missing, 6 harness does not stop the app, 12 commit not a full hash, 14 committed texts missing at HEAD, 5 wav:check failed, 3 router dist proofs failed before or after the run, 4 guard failed. After all of those the exit code is the flight's own.
rem The real guard line passes --require-precheck: without a fresh PRECHECK OK line from the precheck task the guard refuses and the hour does not fly.
rem NOTE ON STYLE: no parentheses inside any echo in an if-block. On 2026-09-20 a guard message citing a commit in parentheses closed its own if-block early, so the exit after it ran unconditionally and a flight died before takeoff with no log of any kind.

=== head-dry ===
@echo off
rem DRY RUN twin of launch-rd.cmd, task Natively-flight-rd-dry: the same preconditions, environment block, commit check, committed-text shas, wav:check, router dist proofs and behavioural guard, then it stops. No flight, no app, no audio, no API call.
rem Generated by gen-launchers-rd.mjs from launch-rd-src.txt. The flight launcher and this one are composed from the same common section, so they cannot drift apart. Never edit this file by hand and never with sed.
rem Its GUARD OK line and its NIGHT GATES OK line are required before the real task is registered. The precheck task starts this task itself and reads its log.
rem Same placeholder rule as the flight launcher: node gen-launchers-rd.mjs with --commit, --t, --deadline-min and --ctx-sha12.
rem Exit codes are the flight launcher's steps before the flight: 9, 8, 7, 6, 12, 14, 5, 3, 4, and 0 when every check passed. This guard line does not pass --require-precheck: no precheck exists yet when the dry twin runs.

rem The commit check: 40 lowercase hex characters, nothing else. An unfilled placeholder, a short hash, a long one and an uppercase one all fail here, before anything runs. findstr cannot count to 40 in a pattern, so the length is tested by substring.
set COMMIT_OK=1
echo %NATIVELY_FLIGHT_COMMIT%| findstr /R /X "[0-9a-f][0-9a-f]*" >nul 2>&1
if errorlevel 1 set COMMIT_OK=0

if not "%NATIVELY_FLIGHT_COMMIT:~40,1%"=="" set COMMIT_OK=0
if "%COMMIT_OK%"=="0" (
  echo NATIVELY_FLIGHT_COMMIT is not a full 40 character hash - the placeholder was not filled in - run gen-launchers-rd.mjs with the commit >> {{ERR}}
  exit /b 12
)
