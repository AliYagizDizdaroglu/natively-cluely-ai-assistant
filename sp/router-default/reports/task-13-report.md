## Deviations and decisions
1. **Probe offset crosses a process boundary.** auto() runs preflight as a CHILD process (runPreflight, execFileSync), so a module variable set in preflight() never reaches auto(). preflight() prints `PROBE_LOG_OFFSET <bytes>` just before the probe wav plays; probe() parses the last such line from the child's output into the module variable `lastProbeOffset` (preflight() also sets it for in-process use). No offset: auto() exits 1 "The hour was NOT spent".
2. `probeSettled(log, { flagOn })`: optional second argument, defaults to auto-detecting a `[Router] dispatch` line; auto passes the env flag. A decision line counts only with `shown=live|pipeline`; dup and unpaired lines (`shown=-`) do not.
3. `flightPlan(env, capturedJson, dry, { promptsFile, roster })`: a 4th argument (prompts path, roster) is needed because the arms' args hold the path. Returns `{ arms, paired, skipped, moveAside, toGrade }`; main() logs the skip warnings from `skipped`. The file moves now run after the prompts step (prompts.mjs does not touch those files). With the variable set, a selected arm that cannot fly (no capture, no cue rule) is skipped and logged, not thrown, and its file is still moved aside. Unknown, duplicate or empty tags throw; main also validates at start, before anything is spent. `done.json` gains `arms` and `focusedOnly: null` only when the variable is set.
4. `buildCaptureFiles` returns two extra fields, `unmapped` (no decision line, or q_at before the first window: the probe's turns) and `problems` (malformed or duplicate capture lines). Nothing throws after the hour. live file = kind live; shadow file = pipeline text (kind shadow, plus kind appended flagged `appended: true`). auto() prints the counts only.
5. The capture files are written only when NATIVELY_LIVE_ROUTER=1 (empty files on a flag-off hour would mislead). They are read from the snapshot's copy of the log and timeline.
6. Router gates: `routerPreflight` lines are `PASS <label>` / `FAIL <label> — detail`. Run in preflight() and again in auto() after the probe wait; failure exits 1 "The hour was NOT spent".
7. M2: `wavMismatch` also requires `fileSize - (dataOffset + 8) === dataLen`. A wav with a trailing extra chunk would now fail too; the builders write none.
