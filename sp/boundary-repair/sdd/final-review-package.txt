   2|  * Puts back the word(s) Deepgram drops at a segment boundary.
   3|  *
   4|  * nova-3 (interim_results, endpointing 300, smart_format) sometimes finalizes a segment SHORT of
   5|  * its own latest interim and starts the next segment after a word that then appears in no final;
   6|  * the turn text is built from finals, so the word is gone before the question is asked. Reproduced
   7|  * at the seam on 2026-09-29 (scratchpad seam-probe.mjs, clips streamed straight to Deepgram with
   8|  * the app's option object): 6 of 20 plays lost a word, then 9 of 48. Flight h40c R22 is the symptom:
   9|  *
  10|  *   interim  "How do you cut hallucinations in a rag answer without just making"
  11|  *   final    "How do you cut"
  12|  *   final    "in a rag answer without just making it refuse?"
  13|  *
  14|  * and the app dispatched "How do you cut in a rag answer without just making it refuse?".
  15|  *
  16|  * This is rule v4 of the design brief (scratchpad boundary-repair/DESIGN-v4.md), a port of
  17|  * rule-v4.mjs, line for line except v2's alignment guard (rule-v4.mjs:64), which the non-ASCII
  18|  * guard makes unreachable (re-review M-a); the two must agree event for event (check-v4.mjs
  19|  * proves the reference on every recorded stream; the controller replays the built module the
  20|  * same way).
  21|  *
  22|  *   CUT    a final F1 whose tokens equal the preceding interim I's first |F1| tokens (strict), or
  23|  *          all but F1's last token, which must be a RE-SPELLING of I's token at that position
  24|  *          (tolerant: Deepgram re-spells the word at the cut, "RAC" -> "Rag", 5 of 5 seam plays of
  25|  *          S2Q07) — see isRespelling(). I must be longer than F1 and ASCII-LETTERED (the tokens
  26|  *          are ASCII: accented English such as "résumé" stays aligned but tokenises as fragments,
  27|  *          and a lost "résumé" came back as "r sum" in the 2026-09-29 review's probe; 0 such
  28|  *          interims in the 28 English logs and the seam recordings). The ASCII-letter condition
  29|  *          is also what keeps rawTok() index-aligned with tok(): no character it admits changes
  30|  *          the token count, checked on every code point in the 2026-09-29 v4 re-review. T = I's
  31|  *          tokens after F1; Traw = the same words in I's own spelling.
  32|  *   PAUSE  clear() forgets the cut and the latest interim (the adapter calls it on an empty FINAL and
  33|  *          on UtteranceEnd); a final with speechFinal (Deepgram heard the utterance end there) leaves
  34|  *          no cut. None of the three occurred inside a repaired loss on the recorded data: 0 of 29 log
  35|  *          repairs had an empty final between F1 and F2, 0 of 6 seam repairs an UtteranceEnd, and all
  36|  *          63 seam cuts had speech_final=false.
  37|  *   REPAIR on the NEXT final F2 only, within REPAIR_WINDOW_MS of F1, when F2 does not simply start
  38|  *          with T[0] (the normal case, 527 in the logs: the word moved to the next segment): for
  39|  *          k = 1 then 2 (k < |T|), if F2's first min(2, |T| - k) tokens EXACTLY equal T[k..], emit
  40|  *          Traw[0..k) + ' ' + F2. Anything else, and every interim, passes through unchanged.
  41|  *
  42|  * Measured over every run log and both seam recordings (check-v4.mjs, 2026-09-29): non-holdout logs
  43|  * 25 repairs, all 25 TRUE against the scripted question (the measured precision; 25 is a floor on

  45|  * 4 / 4 TRUE — reported only, NOT an independent validation and not evidence for any choice here

  65| /**
  66|  * The longest F1 -> F2 gap among the repaired losses was 3715 ms (logs; 3115 holdout, 3207 seam); the
  67|  * margin keeps a tail from being glued onto the next, unrelated utterance. NORMAL cuts (nothing lost)
  68|  * reach 7835 ms, 12 of 527 past 5000, so the window will occasionally miss a real loss.
  69|  */

  71| /** The largest skip observed: 1 loss of 2 words, 25 of 1 (non-holdout logs). */
  72| const MAX_SKIPPED_WORDS = 2;
  73| /** Resumption tokens that must match exactly: 2 — the evidence every observed loss provides — or 1 when the interim holds no more. */
  74| const RESUME_MATCH_WORDS = 2;
  75| 
  76| /** Comparison tokens: thousands commas between digits removed ("10,000" -> "10000"), lowercase, [a-z0-9']+ runs — the evidence scans' normalisation. */
  77| const stripThousands = (s: string): string => s.replace(/(\d),(\d)/g, '$1$2');
  78| const tok = (s: string): string[] => stripThousands(s).toLowerCase().match(/[a-z0-9']+/g) ?? [];
  79| /** The same tokens in the text's own spelling (not lowercased): index-aligned with tok() on any text without a non-ASCII letter — the NON_ASCII_LETTER guard in createBoundaryRepair is what guarantees it. */
  80| const rawTok = (s: string): string[] => stripThousands(s).match(/[A-Za-z0-9']+/g) ?? [];
  81| /** A letter or combining mark outside ASCII: the tokenisers split such a word into fragments, so an interim holding one is never a cut (2026-09-29 review M2). */
  82| const NON_ASCII_LETTER = /(?![\x00-\x7F])[\p{L}\p{M}]/u;
  83| 
  84| /**
  85|  * F1's last token may only be a RE-SPELLING of the interim's token at that position: same first
  86|  * letter, no digit, no longer. smart_format writes "ninety two percent" as "92%" — one final token
  87|  * over three interim words — and a compound merges "all right" into "Alright": a final token that
  88|  * absorbed more audio than the interim's word shifts T, and v3 restored "two percent" / "right"
  89|  * (the spec review's probes). Measured on the 42 tolerant cuts in the NON-HOLDOUT logs and seam
  90|  * recordings (check-v4.out.txt): all 34 kept are no longer than the interim's token ("xgboost" ->
  91|  * "xg", "dashboard" -> "dash", "RAC" -> "Rag"); 7 refused as longer (all "break" -> "breaks") and
  92|  * 1 for a digit ("ninety" -> "92"), none of them followed by a repair; 0 refused for the first
  93|  * letter, but check-v4 counts each cut under the FIRST rule that refuses it (digit, longer, first
  94|  * letter), and a spelled-out number never shares its first character with its digits, so
  95|  * "ninety" -> "92" fails the first-letter rule too: "1 digit, 0 first letter" only reflects that
  96|  * order. The data isolates neither rule; the digit rule rests on the synthetic "v2" for "version"
  97|  * case, the first-letter rule on the synthetic "put" for "cut" case. KNOWN RECALL COST: an
  98|  * inflection is longer too, and it does not shift T (the 7 "breaks" cuts are aligned: F2 resumed at
  99|  * the interim's next word, nothing lost); a word lost right after an inflected cut ("scale" ->
 100|  * "scales", then "horizontally") was restored by v3 and is not by v4. No such loss in the data.
 101|  */
 102| const isRespelling = (finalTok: string, interimTok: string): boolean =>
 103|     finalTok[0] === interimTok[0] && !/\d/.test(finalTok) && finalTok.length <= interimTok.length;

 105| export interface BoundaryRepairResult {
 106|     /** What to emit: `text` as received, or the restored word(s) + ' ' + `text`. */
 107|     text: string;
 108|     /** The restored word(s) in the interim's own spelling, in order; null when nothing was restored. */
 109|     restored: string[] | null;
 110| }
 111| 
 112| export interface BoundaryRepair {
 113|     /**
 114|      * One call per NON-EMPTY Transcript event, in arrival order; `atMs` is the arrival time (only
 115|      * finals read it); `speechFinal` is Deepgram's speech_final flag (a final carrying it leaves no cut).
 116|      */
 117|     onTranscript(text: string, isFinal: boolean, atMs: number, speechFinal?: boolean): BoundaryRepairResult;
 118|     /** A pause (an empty final, an UtteranceEnd): forget the remembered cut and the latest interim. */
 119|     clear(): void;
 120| }
 121| 
 122| export function createBoundaryRepair(): BoundaryRepair {
 123|     let lastInterim: string | null = null;
 124|     let cut: { T: string[]; Traw: string[]; atMs: number } | null = null;
 125|     return {
 126|         clear() {
 127|             cut = null;
 128|             lastInterim = null;
 129|         },
 130|         onTranscript(text, isFinal, atMs, speechFinal = false) {
 131|             if (!isFinal) {
 132|                 lastInterim = text;
 133|                 return { text, restored: null };
 134|             }
 135|             let out = text;
 136|             let restored: string[] | null = null;
 137|             const remembered = cut;
 138|             if (remembered && atMs - remembered.atMs <= REPAIR_WINDOW_MS) {
 139|                 const T = remembered.T, f = tok(text);
 140|                 if (f.length && f[0] !== T[0]) {
 141|                     for (let k = 1; k <= MAX_SKIPPED_WORDS && k < T.length && !restored; k++) {
 142|                         const m = Math.min(RESUME_MATCH_WORDS, T.length - k);
 143|                         if (f.length >= m && T.slice(k, k + m).every((w, j) => w === f[j])) restored = remembered.Traw.slice(0, k);
 144|                     }
 145|                 }
 146|                 if (restored) out = `${restored.join(' ')} ${text}`;
 147|             }
 148|             cut = null;
 149|             if (lastInterim && !speechFinal && !NON_ASCII_LETTER.test(lastInterim)) {
 150|                 const iw = tok(lastInterim), fw = tok(text), raw = rawTok(lastInterim);
 151|                 if (fw.length > 0 && fw.length < iw.length) {
 152|                     const strict = fw.every((w, i) => w === iw[i]);
 153|                     const tolerant = !strict && fw.length >= 2 && fw.slice(0, -1).every((w, i) => w === iw[i]) && isRespelling(fw[fw.length - 1], iw[fw.length - 1]);
 154|                     if (strict || tolerant) cut = { T: iw.slice(fw.length), Traw: raw.slice(fw.length), atMs };
 155|                 }
 156|             }
 157|             lastInterim = null;
 158|             return { text: out, restored };
 159|         },
 160|     };
 161| }

   4| //
   5| // The `Transcript event` line keeps Deepgram's RAW text (the offline scans parse it), but since the
   6| // boundary repair (deepgramBoundaryRepair.ts, 2026-09-29) the app emits the REPAIRED final; the
   7| // restore is logged on the very next line by the same synchronous handler:
   8| //   [DeepgramStreaming] boundary repair: restored "<words>" before "<first 40 chars of the raw final>"
   9| // so a final directly followed by that line replays as `<words> <raw>`. A repair line anywhere else
  10| // (no final right above it, or under a final its `before` text does not name) refuses: that log is not
  11| // what the app saw. Logs from before the repair hold no such line and parse exactly as they always did.
  12| const FINAL = /^(\S+) \[LOG\] \[DeepgramStreaming\] Transcript event — isFinal=true, text="((?:[^"\\]|\\.)*)"/;
  13| const REPAIR = /^\S+ \[LOG\] \[DeepgramStreaming\] boundary repair: restored "((?:[^"\\]|\\.)*)" before "/;
  14| const unq = (s) => JSON.parse(`"${s}"`);
  15| /** @returns {{ at: number, text: string }[]} non-empty finals at or after sinceMs, in log order */

  17|     const lines = dbg.split('\n');
  18|     const out = [];
  19|     for (let i = 0; i < lines.length; i++) {
  20|         const m = lines[i].match(FINAL);
  21|         if (!m) {
  22|             if (REPAIR.test(lines[i]) && !FINAL.test(lines[i - 1] ?? '')) throw new Error(`finalsFrom: line ${i + 1} is a boundary repair with no final directly above it`);
  23|             continue;
  24|         }
  25|         const rep = lines[i + 1]?.match(REPAIR);
  26|         if (rep && !lines[i + 1].includes(`before "${m[2].slice(0, 40)}"`)) throw new Error(`finalsFrom: line ${i + 2} is a boundary repair for another final than line ${i + 1}`);

  28|         const at = Date.parse(m[1]);
  29|         if (text && at >= sinceMs) out.push({ at, text });
  30|     }
  31|     return out;
  32| }
